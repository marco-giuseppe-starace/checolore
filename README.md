# CheColore

Trasforma l'orario scolastico in un codice colore abbinato alle copertine di quaderni e libri, per famiglie con più figli.

Stack: Laravel 12 + Vue 3 + Vuetify 3 (stesso pattern di mantafix/pranzia).

- `/` mostra la landing page di validazione agli ospiti (servita come file statico da `resources/landing/index.html`)
- utenti autenticati atterrano nella SPA (`resources/js/`), ancora in fase iniziale

Live: https://checolore.marcostarace.it
